# Маджонг — классика, матчи 1 на 1 и игра с другом

Веб-версия маджонг-пасьянса с двумя режимами: спокойная **Классика** без
соперника и онлайн-**Дуэль 1 на 1** — как в Vita Mahjong: живой человек
напротив (быстрый матч одной кнопкой, вход в открытую комнату из списка
или по коду), одинаковая доска у обоих, гонка в реальном времени,
счёт серии побед между вами, трофеи и лиги от Бронзы до Легенды.
Зелёное сукно стола, «костяная» графика, спокойные плавные анимации и звук.

## Как играть

- При запуске открывается **меню** (последняя партия сохранена и ждёт
  кнопки «Продолжить»). Вход на уровень с прогрессом спросит:
  «Продолжить или начать заново?».
- **Два режима на выбор** (экран «Меню»): Классика — без таймера и соперника;
  **1 на 1** — экран дуэли: большая кнопка **«Играть»** (быстрый матч — сервер
  сам подберёт соперника, уровень не важен), под ней живой список **открытых
  игр** (кто ждёт прямо сейчас — вход одним тапом), ниже — **игра по коду**
  и **против компьютера**.
- **Настройки** (шестерёнка в меню): язык **Русский/English** и звук.
- **Таблица** (кубок в меню): классика (уровни, пары, партий),
  матчи (лига, трофеи, победы/поражения, серия) и друзья (итоги
  встреч с каждым другом: игр, П—П, винрейт).
- **Тапни по свободной плитке** — она улетает в лоток сверху (зажатая
  плитка не поддаётся: сверху пусто и открыт бок).
- **Две одинаковые** в лотке — поднимаются над лотком и взрываются,
  остальные тихонько соскальзывают на их место.
- **Четыре разных** в лотке — конец игры (кнопка «Отменить» спасает).
- **Рубашки двух видов**:
  - свободные — тапни, плитка перевернётся; найди такую же открытую —
    обе улетят в лоток парой (открытая переворачивается обратно, если
    тапнуть другую);
  - спрятанные ПОД другими костями — лежат лицом вниз, пока верхняя
    кость не снята; как только сверху пусто, рубашка открывается сама.
- **Ходов больше нет** — игра сама тихо перемешает доску бесплатно
  (как в топовых маджонгах), застрять насухо нельзя.
- **Удерживай СВОБОДНУЮ плитку пальцем** — она приподнимется,
  и увидишь, что под ней (зажатые не поднимаются).
- **«Заново» во время игры** сначала спросит подтверждение —
  случайный тап не снесёт прогресс.
- **Подсказка**, **перемешивание** и **отмена** — ограничены (бейджи
  с числом на кнопках), за победу даются бонусы. Потолки: возвраты ≤ 5,
  перемешивания ≤ 5, подсказки ≤ 15.
- **Бонус закончился** — тап по его кнопке предлагает получить 1 бонус
  за просмотр рекламы (Рекламная сеть Яндекса, блок R-M-20010647-1;
  в вебе при недоступности блока показывается демо-ролик с таймером —
  механика награды работает всегда).
- **Планшеты и повороты**: раскладка подбирается под ориентацию экрана
  (портрет/альбом), плитки и текст автоматически крупнее на больших
  экранах, доска с аккуратными полями от краёв.
- **Бесконечные уровни**: чип «Уровень N» сверху и лестница без конца;
  сложность циклится и никогда не растёт бесконечно — как и число
  плиток (максимум 80, доска не шире 6×8).
- **Цвет рубашек** меняется от уровня к уровню (не часто — каждые
  5 уровней): зелёный → синий → винный → аметист → бронза.
- В матче 1 на 1: **комбо** (до ×5), челлендж **«Божественный ход»** (+150),
  **трофеи** +30–50 за победу / −15 за поражение, **лиги** Бронза → Легенда.
- **Онлайн-дуэль**: одинаковая доска у обоих (генерируется на сервере), матч
  идёт по серверному таймеру, ходы соперника приходят мгновенно (WebSocket).
  Перезагрузка страницы возвращает в матч; если соперник пропал — баннер
  «потерял связь», через 30 секунд честный итог. Реванш и «дальше» стартуют
  только когда оба согласились.
- **Счёт серии побед**: играете с одним человеком несколько партий подряд —
  в панели матча и на итоговом экране виден счёт «Вы 3 : 1 Соперник».
  Серия живёт, пока вы двое в одной комнате: реванш и «дальше» её
  не сбрасывают.

## Стек

- [Next.js 16](https://nextjs.org) (App Router) + React 19
- Tailwind CSS 4
- Zustand (сохранение прогресса и лиги в localStorage)
- Все раскладки генерируются решаемыми (reverse-solve алгоритм)
- Соперник — локальный ИИ с «живым» темпом (разгоны и паузы)
- Двуязычный интерфейс (ru/en), реклама с вознаграждением (Яндекс.РС),
  знаки на костях — без красного «萬»: только крупная цифра по центру,
  плитки-«полоски» 一二三 различаются мгновенно

## Деплой на Vercel

1. **Загрузите проект на GitHub**
   - Вариант А (через сайт): создайте новый репозиторий → «uploading an existing
     file» → перетащите содержимое этой папки (все файлы, включая `.gitignore`).
   - Вариант Б (через git):
     ```bash
     git init
     git add .
     git commit -m "Mahjong Solitaire"
     git branch -M main
     git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПО.git
     git push -u origin main
     ```
2. **Подключите Vercel**: [vercel.com](https://vercel.com) → **Add New → Project**
   → выберите репозиторий → **Deploy**.
   - Framework Preset определится сам: **Next.js**
   - Build Command: `next build` (по умолчанию)
   - Ничего настраивать не нужно — просто нажмите Deploy.
3. Через минуту получите публичную ссылку вида `https://имя-проекта.vercel.app`.
   Дальше каждое обновление репозитория на GitHub деплоится автоматически.
4. **Мультиплеер**: работает сразу после деплоя — клиент подключается
   к серверу Deno Deploy по адресу
   `wss://mahjong-solitaire.damirkolmurzin.deno.net` (адрес зашит в
   `src/lib/rooms/roomApi.ts` константой `PROD_WS_URL`; локальная
   разработка автоматически ходит на `ws://localhost:8080`).

## Мультиплеер-сервер (Deno Deploy)

Матчи 1 на 1 работают через отдельный WebSocket-сервер — **один файл**
`deno-server/main.ts` (комнаты, seed раскладок, авторитарное время,
матчмейкинг, лобби открытых игр, счёт серии побед; состояние — в
Deno KV, поэтому переживает смену изолята).

### Деплой сервера (Playground — именно так, НЕ «New Project»)

1. Откройте [dash.deno.com](https://dash.deno.com) → **New Playground**
   (пустой).
2. Удалите содержимое редактора, вставьте **весь** файл
   `deno-server/main.ts` из этого архива (Ctrl+A → удалить → вставить).
3. Нажмите **Save & Deploy** — через несколько секунд сервер будет
   жить по адресу вида `https://имя.deno.net`.
4. Никаких переменных окружения не нужно: сервер принимает
   WebSocket на **любом пути** (клиент подключается просто к корню
   `wss://имя.deno.net`).

Адрес сервера зашит в клиенте одной константой
(`PROD_WS_URL` в `src/lib/rooms/roomApi.ts`) — если у вас другое имя
Playground, поменяйте её и перезалейте клиент (Vercel → Redeploy).

### Экономия бесплатных лимитов Deno Deploy

Клиент в игре шлёт серверу только короткие события: `{t:'event',
kind:'match', tile1Id, tile2Id}` в момент сбора пары и `{t:'finish'}`
на финише. Никакого поллинга состояния и лишнего трафика — всё
актуальное сервер пушит сам (Deno KV watch). Сердцебиение — лёгкий
`hb → ping` раз в 3 секунды (держит NAT и присутствие игрока).

### Локальный запуск (для тестов)

```bash
cd deno-server
deno run --unstable-kv --allow-net --allow-env main.ts   # порт 8080
```

Проверка: `curl http://localhost:8080/health` — ответит
`{"ok":true,"kv":"...",...}`.

## Структура проекта

```
src/
  app/                  # страница, layout, PWA-манифест, глобальные стили
  components/game/      # Board, Tray, HUD, Tile, TileFace, GameScreen, DuelScreen
  lib/mahjong/          # движок: плитки, раскладки, генератор решаемых досок
  lib/game/             # состояние игры, эффекты, слоты лотка
  lib/rooms/            # WebSocket-клиент мультиплеера (roomApi)
  lib/sound.ts          # синтезированные звуки (Web Audio)
deno-server/main.ts     # мультиплеер-сервер (один файл, Deno Deploy)
public/icons/           # PWA-иконки
```
